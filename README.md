# Course Enrolment Web App

A course enrolment web application built using HTML, CSS, Vue.js and Python through Brython.

The app allows students to log in, browse courses, enrol in courses, view enrolment status and drop courses.

## Features

- Student login
- Course browsing by trimester
- Course details
- Course enrolment
- Prerequisite checking
- Timetable clash checking
- Approval-required enrolments
- Course dropping
- Enrolment status badges
- Responsive layout
- External course and student data loading
- Fallback sample data if the external data cannot be reached

## Technologies Used

- HTML
- CSS
- Python
- Brython
- Vue.js
- JSON
- External API data
